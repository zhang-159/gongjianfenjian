# 项目整合方案

## 1. 概述

### 1.1 目标

将01-05模块整合为统一的主程序，QT界面调用同一套底层库，实现：
- 数据生成（STL → 点云 → 姿态采样）
- 特征提取（ESF / OUR-CVFH）
- 索引入库（FAISS索引构建）
- 类别识别（自适应特征库选择）
- 位姿配准（SAC-IA + ICP）

### 1.2 架构原则

| 原则 | 说明 |
|------|------|
| 模块独立 | 01-05保持独立开发，可单独编译测试 |
| 接口稳定 | 模块通过头文件暴露API，内部实现可随时修改 |
| 分工明确 | 不同人负责不同模块 |
| 可测试 | 每个模块有独立的单元测试 |
| 可替换 | 算法升级只需替换对应模块库 |

## 3. 模块接口设计

### 3.1 01_sim_data_gen 接口

```cpp
// sim_data_gen.h
#pragma once

#include <string>
#include <vector>
#include <pcl/point_cloud.h>

namespace sim_data_gen {

// 配置结构
struct SamplingConfig {
    int samples_per_edge = 15;
    float points_per_mm2 = 0.1f;
    bool enable_unit_standardization = false;
    bool enable_centering = true;
    bool enable_pca_alignment = true;
    int target_points = 0;
};

struct ExtrinsicConfig {
    float rx_min = 0.0f, rx_max = 80.0f, rx_step = 20.0f;
    float ry_min = 0.0f, ry_max = 80.0f, ry_step = 20.0f;
    float rz_min = 0.0f, rz_max = 360.0f, rz_step = 20.0f;
    float tx = 0.0f, ty = 0.0f, tz = 1.0f;
};

struct Pose {
    float rx, ry, rz, tx, ty, tz;
    int pose_id;
    std::string name;
};

// 核心函数
pcl::PointCloud<pcl::PointXYZ>::Ptr readSTL(
    const std::string& file_path,
    const SamplingConfig& config = SamplingConfig{});

std::vector<Pose> generatePoses(const ExtrinsicConfig& config);

pcl::PointCloud<pcl::PointXYZ>::Ptr transformPointCloud(
    const pcl::PointCloud<pcl::PointXYZ>::Ptr& input,
    const Eigen::Matrix4f& transform);

std::vector<pcl::PointCloud<pcl::PointXYZ>::Ptr> batchTransform(
    const pcl::PointCloud<pcl::PointXYZ>::Ptr& input,
    const std::vector<Pose>& poses);

}
```

```cmake
cmake_minimum_required(VERSION 3.20)
project(gongjianfenjian LANGUAGES CXX)

# 依赖
```

## 9. 注意事项

### 9.1 为什么用静态库而非动态库

| 原因 | 说明 |
|------|------|
| PCL依赖复杂 | PCL本身有很多DLL依赖，再用动态库会形成多层依赖链 |
| 部署简单 | 用户只需安装VC++运行库，不需担心DLL版本 |
| 无热更新需求 | 工件识别系统不需要运行时更新模块 |
| 调试方便 | 静态库代码直接进入exe，调试更直接 |

### 9.2 模块独立性

- 每个模块可以独立编译：`cmake --build build --target sim_data_gen`
- 每个模块可以独立测试
- 模块之间仅通过头文件接口通信

### 9.3 命名空间

统一使用项目级命名空间：
```cpp
namespace sim_data_gen { ... }
namespace feature_extraction { ... }
namespace database_build { ... }
namespace category_recognition { ... }
namespace pose_registration { ... }
```
