# 代码迁移指南

## 概述

本文档描述如何将现有的 `gongjianfenjian` 项目从 `.vcxproj` 模式迁移到 CMake 项目结构。

---

## 1. 迁移前准备

### 1.1 备份

```bash
# 在项目根目录下执行
xcopy /E /I /Y gongjianfenjian gongjianfenjian_backup
```

### 1.2 环境要求

| 组件 | 要求 | 确认方法 |
|------|------|----------|
| VS2022 | 17.0+ | 帮助 → 关于 |
| CMake | 3.20+ | cmake --version |
| Qt5 | 5.15+ MSVC | Qt Creator 或 vcpkg |
| PCL | 1.14.0 | 已安装 |
| vcpkg | 最新 | 已集成 |

### 1.3 现有代码统计

```
现有源码文件:
├── 01_sim_data_gen (2个cpp, 3个头文件)
├── 02_feature_extraction (2个cpp, 3个头文件)
├── 03_database_build (2个cpp, 1个头文件)
├── 04_category_recognition (2个cpp, 3个头文件)
├── 05_pose_registration (目录存在但无文件)
└── libs (1个公共头文件)

测试/工具文件（迁移后删除）:
├── 01_sim_data_gen/tools/test_extrinsic_transform.cpp
├── 02_feature_extraction/tools/*.cpp (3个)
├── 03_database_build/src/build_faiss_index.cpp (批处理工具，保留)
└── 04_category_recognition/src/main.cpp (测试程序，删除)
```


**CMakeLists.txt：**
```cmake
# 01_sim_data_gen/CMakeLists.txt
add_library(sim_data_gen STATIC)

target_sources(sim_data_gen PRIVATE
    src/point_cloud/stl_reader.cpp
    src/point_cloud/extrinsic_transform.cpp
)

target_include_directories(sim_data_gen PUBLIC
    $<BUILD_INTERFACE:${CMAKE_CURRENT_SOURCE_DIR}/include>
    $<BUILD_INTERFACE:${CMAKE_CURRENT_SOURCE_DIR}/src>
    $<INSTALL_INTERFACE:include>
)

    common_types
    PCL::PCL
)
```

## 4. 根目录 CMakeLists.txt

```cmake
# CMakeLists.txt
cmake_minimum_required(VERSION 3.20)
project(gongjianfenjian LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

# 输出目录
set(CMAKE_RUNTIME_OUTPUT_DIRECTORY ${CMAKE_BINARY_DIR}/bin)
set(CMAKE_LIBRARY_OUTPUT_DIRECTORY ${CMAKE_BINARY_DIR}/lib)
set(CMAKE_ARCHIVE_OUTPUT_DIRECTORY ${CMAKE_BINARY_DIR}/lib)

# 依赖包
find_package(PCL 1.14 REQUIRED)
find_package(Qt5 REQUIRED COMPONENTS Widgets Core Gui)
find_package(Eigen3 REQUIRED)
find_package(FAISS REQUIRED)

# 公共库
add_subdirectory(libs/common)

# 01-05模块
add_subdirectory(01_sim_data_gen)
add_subdirectory(02_feature_extraction)
add_subdirectory(03_database_build)
add_subdirectory(04_category_recognition)
add_subdirectory(05_pose_registration)

# QT主程序
add_subdirectory(app)
```

## 7. 常见问题

### Q1: 找不到 PCL

**解决：** 在 CMakeLists.txt 中指定 PCL 路径
```cmake
set(PCL_DIR "C:/Program Files/PCL 1.14.0/lib/cmake/PCL")
find_package(PCL 1.14 REQUIRED)
```

### Q2: 找不到 Qt5

**解决：** 指定 Qt5 路径
```cmake
set(Qt5_DIR "C:/Qt/5.15.2/msvc2019_64/lib/cmake/Qt5")
find_package(Qt5 REQUIRED COMPONENTS Widgets)
```

### Q3: 找不到 FAISS

**解决：** 使用 vcpkg 安装的 FAISS
```cmake
set(FAISS_DIR "D:/vcpk/vcpkg/installed/x64-windows/share/faiss")
find_package(FAISS REQUIRED)
```

### Q4: 编译错误：找不到头文件

**解决：** 检查 `target_include_directories` 是否包含所有必要路径
