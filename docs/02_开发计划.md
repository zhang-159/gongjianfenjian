# 02_feature_extraction 仿真数据特征提取 开发计划

## 一、模块目标

为 `01_sim_data_gen` 生成的点云数据提取双特征向量：
- **ESF特征**（640维）—— 基于几何形状分布
- **OUR-CVFH特征**（345维）—— 基于视点不变几何特征

## 二、开发环境

| 组件 | 版本 |
|------|------|
| 编译器 | MSVC VS2022（C++17） |
| PCL | 1.14.0 |
| CMake | 3.20+ |

## 四、开发步骤

### 第1步：创建项目结构

**验收标准**：

- vcxproj包含02的源文件
- 编译项目无报错（空项目）

---

### 第2步：ESF特征提取模块

**任务**：
- 创建 `src/features/esf_estimator.h` —— ESF特征提取器声明
- 创建 `src/features/esf_estimator.cpp` —— ESF特征提取器实现
- 使用 PCL `ESFEstimation<pcl::PointXYZ, pcl::ESFSignature640>`

**ESF特征说明**：
- ESF（Ensemble of Shape Functions）是一种3D形状描述符
- 维度：640维
- 对点云的形状几何分布进行编码
- 对姿态变化具有一定鲁棒性

**验收标准**：
- `esf_estimator.extract(cloud)` 返回 `std::vector<float>` 长度640
- 单点云测试输出640维特征向量

---

### 第3步：CVFH特征提取模块

**任务**：
- 创建 `src/features/cvfh_estimator.h` —— CVFH特征提取器声明
- 创建 `src/features/cvfh_estimator.cpp` —— CVFH特征提取器实现
- 使用 PCL `OURCVFHEstimation<pcl::PointXYZ, pcl::Normal, pcl::VFHSignature308>`
- 需要先估计法线

**CVFH特征说明**：
- CVFH（Clustered Viewpoint Feature Histogram）是VFH的改进版本
- 维度：345维
- 对视点变化具有不变性
- 需要先计算法线（Normal Estimation）

**验收标准**：
- `cvfh_estimator.extract(cloud)` 返回 `std::vector<float>` 长度345
- 单点云测试输出345维特征向量

---

**验收标准**：

- 正确输出ESF特征维度（640）和前10个值

## 五、数据依赖

| 数据 | 路径 | 说明 |
|------|------|------|
| 输入点云 | `data/pointclouds/raw/*.pcd` | 来自01生成的姿态点云 |
| ESF特征 | `data/esf_features/*.esf` | 提取后的ESF特征文件 |
| CVFH特征 | `data/cvfh_features/*.cvfh` | 提取后的CVFH特征文件 |

## 六、输出数据格式

### ESF特征文件（.esf）
每行格式：`filename,dim_0,dim_1,...,dim_639`

### CVFH特征文件（.cvfh）
每行格式：`filename,dim_0,dim_1,...,dim_344`

## 七、注意事项

1. **法线估计**：CVFH需要先估计法线，法线估计的搜索半径需要合理设置
2. **点云点数**：ESF/CVFH对输入点云点数有一定要求，建议2048~8192点
3. **坐标系**：输入点云应为已居中、未旋转的标准化点云
4. **批量处理**：本阶段仅开发单点云测试，批量处理在后续阶段实现
