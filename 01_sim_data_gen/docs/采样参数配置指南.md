# STL→PCD 采样参数配置指南

## 一、参数说明

### SamplingConfig 参数详解

| 参数 | 默认值 | 调整范围 | 说明 |
|------|--------|----------|------|
| `samples_per_edge` | 15 | 5-50 | 三角面边缘采样点数 |
| `points_per_mm2` | 0.1 | 0.01-1.0 | 三角面内部采样密度 |
| `target_points` | 0 | 1024-8192 | 目标点数，0=完整采样 |
| `enable_unit_standardization` | false | - | 单位标准化（米→毫米） |
| `enable_centering` | true | - | 质心居中到原点 |
| `enable_pca_alignment` | true | - | PCA主轴对齐XYZ |

### 参数调整建议

| 参数 | 说明 | 调整原则 |
|------|------|----------|
| `samples_per_edge` | 边缘采样点数 | 点数多→调小，特征细节重要→调大 |
| `points_per_mm2` | 内部采样密度 | 精度要求高→调大，存储限制→调小 |
| `target_points` | 目标点数 | 匹配识别算法输入要求（推荐2048） |

---

## 二、工程场景配置建议

### 场景1：快速测试
适用于开发初期验证功能

```cpp
SamplingConfig config;
config.samples_per_edge = 5;
config.points_per_mm2 = 0.01;
config.target_points = 2048;
config.enable_centering = true;
config.enable_pca_alignment = true;
```

**特点**：点数少、速度快、适合快速迭代

---

### 场景2：特征提取（数据库构建）
适用于生成仿真数据库，需要高质量点云

```cpp
SamplingConfig config;
config.samples_per_edge = 15;
config.points_per_mm2 = 0.1;
config.target_points = 0;  // 完整采样
config.enable_centering = true;
config.enable_pca_alignment = true;
```

**特点**：保留完整几何特征，适合特征提取算法

---

### 场景3：实时识别
适用于现场点云处理，需要平衡速度和精度

```cpp
SamplingConfig config;
config.samples_per_edge = 10;
config.points_per_mm2 = 0.05;
config.target_points = 2048;
config.enable_centering = true;
config.enable_pca_alignment = true;
```

**特点**：点数固定、处理速度快

---

### 场景4：小尺寸工件
适用于尺寸较小的精密零件

```cpp
SamplingConfig config;
config.samples_per_edge = 20;
config.points_per_mm2 = 0.2;
config.target_points = 2048;
config.enable_centering = true;
config.enable_pca_alignment = true;
```

**特点**：更高采样密度，保留小尺寸特征

---

### 场景5：大尺寸工件
适用于大型机械零件

```cpp
SamplingConfig config;
config.samples_per_edge = 10;
config.points_per_mm2 = 0.05;
config.target_points = 4096;
config.enable_centering = true;
config.enable_pca_alignment = true;
```

**特点**：适当降低密度，避免点数过多

---

## 三、单位说明

| 坐标系单位 | 配置 |
|------------|------|
| 毫米（mm） | `enable_unit_standardization = false` |
| 米（m） | `enable_unit_standardization = true` |
